这个页面用于手动跑通后端核心链路：健康检查、注册登录、资料上传、解析任务、AI 摘要、 向量化后的 RAG 问答，以及学习辅助计划。它只依赖当前 Spring Boot 静态资源能力，不需要单独启动前端工程。

基础配置

1. 用户身份

先注册或登录，后续受保护接口会自动带上 JWT。

2. 普通资料上传

支持 PDF、PPT/PPTX、Word/DOCX、TXT、Markdown、MP4、MP3、WAV 等后端已校验的类型。

3. 解析任务与内容

上传成功后会创建异步解析任务；这里可以查询任务状态，也可以手动触发一次解析调度。

4. AI 摘要与学习辅助

这里会走 AiGateway。若本地配置启用了真实 LangChain4j Provider，会调用真实模型。

5. 基于资料的 RAG 问答

问答会基于 materialId 对应的切片向量召回结果组织上下文，不是普通闲聊接口。
